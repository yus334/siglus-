# 字体已就位

当前 `default.ttf` = 系统自带的 **黑体（simhei.ttf，9.3 MB）**，覆盖：

- 简体中文（GBK）
- 日文平假名 / 片假名（GBK 含假名区）
- 常见标点与符号

`game.ini` 里的配置：

```ini
[text]
font       = font/default.ttf
font_size  = 28
face_index = 0
```

## 想换字体

直接覆盖 `default.ttf`，或改 `game.ini` 的 `font` 指向别的文件。

| 系统字体 | 大小 | 说明 |
|---|---|---|
| `C:\Windows\Fonts\msyh.ttc` | 18.8 MB | 微软雅黑，中文观感最好（TTC 集合） |
| `C:\Windows\Fonts\YuGothM.ttc` | 13.3 MB | 游ゴシック，日文游戏首选（TTC 集合） |
| `C:\Windows\Fonts\simhei.ttf` | 9.3 MB | 黑体，**当前使用的**，单文件、体积小 |
| `C:\Windows\Fonts\simsun.ttc` | 17.5 MB | 宋体（TTC 集合） |

`.ttc` 是字体集合，里面有多套字重/字形，用 `face_index` 选择（0 开始）。
代码按文件头的 `ttcf` 标记自动识别，扩展名写成什么都行。

## ruby 注音

脚本里写 `[漢字](かんじ)` 会以 0.5 倍字号把注音画在正文上方，
字体需要同时包含汉字与假名才能正常显示。
